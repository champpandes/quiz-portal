Getting started

  1. Create a subject, e.g. Math 7.
  2. Add a period inside it, e.g. 1st Quarter.
  3. Add questions to that period, or bulk upload them.
  4. Create a quiz that pulls from the period.
  5. Share the quiz link with your students.
  6. Check results as they come in.
